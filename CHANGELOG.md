# Changelog

## 0.1.0 — 2026-11-15

- First repository package of the perspective 16:9 panorama shader and local PTZ dock.
- Pan, tilt, roll and horizontal FOV; locked-by-default preview gestures.
- Dynamic named presets, clear/delete, JSON import/export and inner/outer home view.
- Automatic horizontal/vertical compact bar with Expand and Stop.
- English, German and Spanish dock localization.
- Sanitized image-only scene collection, neutral demo presets, Windows path helper and English illustrated setup guides.
- Separate storage namespace and example defaults for the public package; existing development scenes/presets are not migrated or modified.
